# anna-lena guske site

Personal website of Anna-Lena Guske, built with Zola (static site generator). Content in `content/`, templates in `templates/`, styles in `sass/`, config in `config.toml`.

- Local server: `zola serve`. Production build: `zola build` (output in `public/`, ignored).
- Deploy runs from `.github/workflows/deploy.yml`.
- Commits follow Conventional Commits (see the commit-conventions rule). See CONTRIBUTING.md for the agnostic-ai workflow.
